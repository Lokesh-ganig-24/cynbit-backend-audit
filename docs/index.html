01 / PROJECT OVERVIEW

About This Assessment

This project evaluates observable technical behaviour on Cynbit's public website and demonstrates a possible backend implementation for handling contact inquiries.

01

Website Analysis

03

Reference Implementation

An independent Java Spring Boot application demonstrating validated contact inquiry submission and MySQL persistence.

02 / TECHNICAL OBSERVATIONS

Website Audit Findings

The following observations are based on passive analysis of the publicly accessible website and its client-side resources.

Frontend Framework

Next.js-related client resources and React Server Components were observed.

Hosting Infrastructure

Response headers contained Vercel infrastructure indicators, including cache-related headers.

Contact Form

Five fields were observed: full name, email, company, industry and message.

Submission Mechanism

The client bundle references a Next.js Server Action named submitInquiry.

Response Handling

The frontend contains loading, success and generic error interface states.

Security Scope

Server-side implementation and internal security controls were not directly inspected.

Important: These are observations of publicly accessible website behaviour. They do not establish Cynbit's actual backend framework, database, server-side validation, persistence mechanism or internal security configuration.

04 / IMPLEMENTATION

Independent Spring Boot Backend

A reference backend was developed to demonstrate a maintainable contact inquiry workflow using Java, Spring Boot and MySQL.

REST Endpoint

POST /api/v1/inquiries

Accepts contact inquiry data and returns a successful creation response.

Data Validation

Required fields, email format and input size constraints are validated before persistence.

Database Persistence

MySQL stores inquiry records using a dedicated contact_inquiries table.

Technology Stack

Java 25 Spring Boot 4.1.2 Spring Web Spring Data JPA Hibernate MySQL 8 Jakarta Validation Maven Spring Boot Actuator
The backend is an independently developed reference implementation. It is not Cynbit's original backend source code.
05 / ENGINEERING IMPROVEMENTS

Backend Recommendations

The following are general engineering recommendations for a reliable and secure contact inquiry workflow.

Input Validation

Apply server-side validation, input length limits and consistent error responses.

Spam Protection

Introduce rate limiting, abuse detection and appropriate spam protection.

Error Handling

Use consistent exception handling, structured logging and safe client-facing error messages.

Database Management

Use database migrations, appropriate indexes and a defined data retention policy.

Monitoring

Monitor service health, API response times and application errors.

Privacy and Security

Protect inquiry data, restrict database access and manage secrets through environment variables.
